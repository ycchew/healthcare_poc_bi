Key Patterns:
- Duplicates: DISTINCT ON (mrn) ORDER BY mrn, last_visit_date DESC
- Unique indexes: DISTINCT ON (mrn, branch) for composite keys
- Casting: column::TEXT for PG name types; return_df=True for DB queries
- Env vars: .strip() os.getenv() values; never default passwords — raise error
- Scheduling: pgAgent only (Windows); pg_cron unavailable
- Ambiguous columns: always alias-prefix in SELECT/GROUP BY/ORDER BY
- Date math: (CURRENT_DATE - date)::INTEGER, not EXTRACT(DAY FROM)
- _rm suffix: exists in collection_report only, NOT in collection
- LATERAL join: LEFT JOIN LATERAL (SELECT ... LIMIT 1) for cross-table fetch
- PostGIS: ST_SetSRID(ST_MakePoint(lng, lat), 4326); GIST indexes on geometry
- Haversine: 2 * 6371 * ASIN(SQRT(...)); DBSCAN: eps_rad = eps_km / 6371.0
- Branch pairs: LEAST/GREATEST for alphabetical ordering in unique constraints
- PG settings: current_setting('geo.project_root', TRUE) for configurable paths

Schema Reminders:
- Patient PK: location (mrn has duplicates!)
- Collection PK: row_number (NOT id); date field: date (NOT transaction_date)
- Amount: amount_collected (NOT net_amount); DOB: dob (NOT date_of_birth)
- City/state: city_name, state_name (NOT city, state)
- CLTV columns: predicted_clv_* (NOT predicted_cltv_*)
- Schema: dk only; source tables: collection, collection_report, patient
